# DroidBridge 功能（回答用法问题只依据这里）

- 投屏与操作：左侧设备列表点设备即投屏。左键点击/拖动，右键或 Esc 返回，中键主页，滚轮滚动，聚焦画面后可打字，Ctrl+V 粘贴电脑剪贴板。
- 右侧图标栏：电源、音量、旋转、截图（相机）、录屏、输入文字、日志、性能数据（脉搏图标）、文件夹、耳机（声音）；"…"里有通知栏、熄屏投屏、安装 APK、重连、应用管理、文件管理、切换为无线连接。
- 连接设备：手机开启 开发者选项 → USB 调试，连电脑后在手机上点"允许"；小米等还需开启"USB 调试（安全设置）"才能点击和输入。侧栏"本机"下"如何连接"有说明。
- 无线连接：点"本机"旁的 Wi-Fi 图标（远程电脑在其"…"菜单选"无线连接设备…"），可扫码配对、填配对码（Android 11+）或按 IP 连接；USB 设备可在"…"里"切换为无线连接"。手机和电脑需在同一网络，地址会被记住并自动重连。
- 远程电脑：同一局域网里运行 DroidBridge 的电脑会出现在"在局域网中发现"，点 + 添加，对方需点"允许"；也可手动填 IP（默认端口 8730）。macOS/Linux 可通过 SSH 安装。
- 设备日志：图标栏"日志"打开 logcat 面板；可按级别、关键字（空格为"且"，-词 为排除）、应用过滤，点 ⊙ 只看前台应用；可暂停、清空、保存。日志行右键"问 AI"可让 AI 助手分析。
- 性能浮层：图标栏脉搏图标，显示前台应用帧率、CPU、内存、温度、电量，每秒刷新。
- 应用管理："…"→ 应用管理，可启动、强制停止、清除数据、卸载；应用右键"AI 诊断"。OPPO/一加/realme 清除数据需在开发者选项打开"禁止权限监控"。
- 文件管理：图标栏文件夹图标或"…"→ 文件管理，只能访问 /sdcard；可上传（拖入）、下载、重命名、删除、安装 APK。
- 安装 APK / 传文件：把文件拖到画面上，APK 安装，其他文件传到 /sdcard/Download。批量安装：侧栏顶部安装包图标，可装到多台设备。
- 截图录屏与相册：截图 PNG、录屏 WebM/MP4，在相册里浏览、复制、下载。
- 群控：打开两台以上设备，在设备标题栏点链接图标加入群控，操作同步到所有群控设备。
- 声音：耳机图标或 设置 → 声音，需 Android 11+。
- 多人同看：多人看同一台设备共用一路投屏，同一时间只有一人能操作，停手 3 秒释放。
- 插件：设置 → 插件，可启用、配置、从插件源安装和更新。
- 浏览器访问：本机 http://localhost:8730，其他设备 https://<电脑IP>:8731。
- 更新：标题栏出现"新版本"时点击即可下载安装，或 设置 → 版本 → 检查更新。
